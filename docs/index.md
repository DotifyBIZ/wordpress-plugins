# WordPress plugins

Small WordPress plugins made by Dotify, one folder each. Nothing here runs on its own: a
WordPress administrator uploads a plugin to a site and activates it.

| Plugin | What it does |
|---|---|
| `menu-order` | Gives posts a menu order and a template, as pages have |
