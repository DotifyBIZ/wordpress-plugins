# Menu order (for site editors)

The plugin *Enable Menu Order for Posts* turns on the page attributes for posts. When you edit
a post you get the same attributes box a page has, with an **Order** field and a template
choice.

To use it, open a post, find the attributes box, and enter a number in **Order**. Which
number sorts first depends on the page or theme that lists the posts.

If you do not see the box, ask your WordPress administrator whether the plugin is active
(see [install and update](admins.md)).
